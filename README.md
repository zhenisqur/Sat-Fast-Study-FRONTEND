# SAT FAST STUDY — Mobile App

Мобильное приложение для подготовки к Digital SAT в стиле Duolingo — не просто банк вопросов, а система, которая честно отслеживает реальный прогресс, приоритизирует слабые темы и не даёт забросить подготовку.

## Идея продукта

Большинство SAT-приложений — это либо статичный банк вопросов (скучно, легко забросить), либо игрушка с фейковыми уровнями, за которой не стоит реальная методика (не готовит к экзамену, просто развлекает). Мы делаем третье: **ежедневный ассистент**, который каждый вечер говорит "делай ровно это", основываясь на реальных данных о том, что ученик знает и не знает — без необходимости самому разбираться, с чего начинать подготовку после уставшего дня в школе.

## Ключевые механики

- **Practice** — тренировочный режим, 50 уровней по каждой секции (Math / Reading & Writing), 15 вопросов на уровень, дневная норма прогрессирует независимо по каждой секции
- **Study** — структурированный путь по 30 официальным доменам College Board (Algebra, Advanced Math, Craft & Structure и т.д.), каждый уровень — 3 обучающих сценария + честный mastery-gate квиз (нужно ответить верно на все вопросы, не один)
- **Mistake Review** *(в разработке)* — вопросы, на которых ученик ошибся, автоматически возвращаются на повторение
- **Диагностика + онбординг** *(в разработке)* — короткий тест при первом запуске калибрует, с каких тем начинать и сколько вопросов реально по силам в день
- Google Sign-In / Apple Sign-In (код готов, дособирается под релиз)

## Технологии

- **React Native + Expo** (SDK 57)
- **TypeScript**
- Собственный JWT-based auth поверх [бэкенда на NestJS](https://github.com/zhenisqur/Sat-Fast-Study-BACKEND) *(ссылка на приватный репозиторий, публичная версия следует)*
- `expo-secure-store` для хранения сессии
- `@react-native-google-signin/google-signin`, `expo-apple-authentication`

```
│   └── profile/           # профиль пользователя
└── services/
    ├── api.ts            # весь слой общения с бэкендом

```

## Запуск локально

```bash
npm install
cp .env.example .env
```

В `.env` пропиши:
```
EXPO_PUBLIC_API_URL=http://ТВОЙ_IP:3000
EXPO_PUBLIC_DEMO_MODE=false
```

Для тестирования на реальном устройстве нужен IP компьютера в локальной сети (не `localhost`), телефон и компьютер должны быть в одной Wi-Fi сети.

```bash
npx expo start
```

Отсканируй QR-код в приложении Expo Go (Android) или через камеру (iOS).

### Demo-режим без бэкенда

Если бэкенд не запущен, установи `EXPO_PUBLIC_DEMO_MODE=true` — приложение будет работать на моковых данных, без реальных сетевых запросов. Полезно для быстрого просмотра UI.
